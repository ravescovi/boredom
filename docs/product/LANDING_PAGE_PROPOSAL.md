# Landing Page Proposal

## Positioning

Bordon.ai should open on the core utility, not a generic marketing splash: "Generate a safe game for the room you are actually in."

## First Viewport

- Brand signal: `Bordon.ai`.
- Primary offer: context-aware game generation.
- Primary action: start with player count, circumstances, type, and props.
- Secondary action: inspect a generated preview.
- Embedded quick-generate form to make the product tangible immediately.

## Trust Signals

Safety constraints should appear in the first scroll:

- No drinking games.
- No gambling or financial stakes.
- No physical-risk mechanics.
- Original rules only.
- Non-commercial generated use.

## Product Narrative

The landing page should explain that the product generates structured JSON first, validates it, and renders Markdown second. That makes the app feel reliable and distinguishes it from a loose chat prompt.

## Deferred Items

- Quota/paywall messaging until pricing is real.
- Auth calls to action until account creation exists.
- Public gallery until moderation and visibility workflows exist.
